5. **DL-025 / PORT-204:** A source-wide audit of all 123 pinned AgonDev libmos
   wrappers found three concrete stack-access defects: `mos_getError` uses
   packed IX+7/IX+10 offsets instead of three-byte slot starts IX+9/IX+12;
   `ffs_setlabel` overwrites its valid HL argument through an uninitialized IX;
   and `mos_flseek_p` points to SP+9 rather than the low 32-bit word at SP+6.
   Minimal local wrappers, compiler call-site evidence, archive/source
   disassembly, and safe runtime cases verify the analysis. An upstream-ready
   report is in `docs/upstream-findings.md`; no upstream checkout was changed.
6. **DL-026:** The same target probe isolated a Fab directory-hostfs limitation:
   file open writes 32-bit `FIL.obj.objsize` with `_poke24`, truncating files
   above 16 MiB and consequently affecting `fsize`/`feof`. Candidate and ZDS
   MOS behave identically. The upstream-ready report distinguishes this from a
   MOS or AgonDev defect; the contract uses the sparse file only for 32-bit
   seek/tell/read and a small file for size/EOF.
