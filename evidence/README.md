# Reproducible evidence

`baseline.json` is the machine-readable result of `scripts/audit_source.py` for
the pinned inputs documented under `research/`. Run `make baseline-check` to
compare an exact research environment with it. This is intentionally stricter
than the portable current-input `make verify` gate. In particular, locally
rebuilt Fab binaries may be functionally valid while differing from the frozen
hashes because build outputs embed user and checkout paths. The baseline gate
also opts into the exact pinned ZDS MOS/map negative control for the historical
oversized-VDP defect; the normal VDP regression reads only the current
candidate.

Compiler output is regenerated by
`make toolchain-probe` and `make c-probe` rather than checked into Git.
`scripts/verify_probe_outputs.py` checks the resulting ADL entry/section layout,
undefined-symbol closure, binary hash/extent, C object count, and aggregate
loadable/BSS sizes against this baseline.

`binary-compare-v3.0.2.json` is a separate reviewed comparison of the current
AgonDev firmware with the official Platform MOS v3.0.2 ZDS build. It pins the
release and candidate identities, raw-image facts, complete handwritten-
assembly range-classification digests, module classifications, source
divergence, and deliberate preparation paths. Recreate and verify it with
`make binary-reference` followed by `make binary-compare`; detailed generated
reports remain in ignored `projects/binary-compare/artifacts/`. The method and
classification limits are documented in `projects/binary-compare/README.md`.
